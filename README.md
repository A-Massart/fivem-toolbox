# Boîte à outils du PAD EMD
## Expérimentations GTA V et FiveM

### Nos mods
- Afficher les coordonées (x, y, z) du joueur : ```player_position```
- Afficher les coordonées (x, y) du repère sur la carte : ```waypoint_position```
- Changer la météo et l'heure : ```weather_and_time```
- Changer le modèle du personnage aléatoirement ou choisi : ```change_ped```
- Modifier les paramètres du véhicule dans lequel est le joueur (couleurs, vitesse, adhérence, le rendre indestructible, etc.) : ```vehicle_settings```

### Les outils utilisés
#### Serveur local  
- FiveM
- FXserver

#### Modifier les textures du jeu
- Special K
- Reshade

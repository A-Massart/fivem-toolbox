# Boîte à outils du modding de GTA V

## Documentation sur le modding du jeu GTA V : **[gta-subversion.eu](https://gta-subversion.eu/)** 
## Expérimentations GTA V et FiveM

### Nos mods
- Afficher les coordonées (x, y, z) du joueur : [```player_position```](https://github.com/PAD-EMD/gtamod-player-position)
- Afficher les coordonées (x, y) du repère sur la carte : [```waypoint_position```](https://github.com/PAD-EMD/gtamod-waypoint-position)
- Changer la météo et l'heure : [```weather_and_time```](https://github.com/PAD-EMD/gtamod-weather-time)
- Changer le modèle du personnage aléatoirement ou choisi : [```change_ped```](https://github.com/PAD-EMD/gtamod-change-ped)
- Modifier les paramètres du véhicule dans lequel est le joueur (couleurs, vitesse, adhérence, le rendre indestructible, etc.) : [```vehicle_settings```](https://github.com/PAD-EMD/gtamod-vehicle-settings)
- Invoquer une arme dans la main ou l'inventaire du joueur : [```weapon_invoke```](https://github.com/PAD-EMD/gtamod-weapon-invoke)
